# Database

## 專案簡介

這是一個以水果銷售與會員管理為主題的資料庫系統專案，目的是整合會員資料、供應商資訊、水果庫存以及訂單交易，讓管理者能夠透過網頁介面快速檢視與維護關鍵資料。

本專案以 Flask 作為後端框架，搭配 SQLAlchemy 與 MySQL，結合 HTML 模板實現簡單的資料管理系統，適合用於資料庫課程、系統設計練習以及後端 CRUD 功能展示。

## 專案目標

- 建立一個可管理會員資訊的系統
- 管理水果基本資料與進貨資訊
- 維護供應商資料與聯絡資訊
- 記錄訂單交易內容與價格資訊
- 提供簡單的網頁操作介面，方便資料新增與檢視

## 主要功能

### 1. 會員管理
- 記錄會員基本資料
- 包含姓名、聯絡方式、地址、年齡、折扣等欄位
- 可管理會員狀態與相關資訊

### 2. 水果管理
- 管理水果商品資料
- 記錄品名、供應商、數量、單位、成本與總價
- 追蹤購入日期與促銷日期

### 3. 供應商管理
- 管理供應商資料
- 記錄供應商名稱、電話、電子郵件、地址與負責人

### 4. 訂單管理
- 記錄會員購買資訊
- 包含水果編號、名稱、購買數量、單價、總金額、折扣後金額與交易日期
- 可追蹤預計交貨與實際交貨日期

## 設計特色

- 採用資料庫驅動的方式管理各項業務資料
- 以簡潔的網頁介面呈現 CRUD 操作
- 將資料模型拆分為會員、供應商、水果、訂單等主要實體
- 適合作為資料庫與後端整合的入門/練習專案

## 專案定位

這個專案屬於小型企業資料管理系統，核心目的是展示資料庫結構與 Web 應用整合的實作方式。它重視資料關聯與業務流程的呈現，適合用來作為 Python + Flask + MySQL 的系統開發範例。

## 簡要總結

本專案以「水果銷售資料管理」作為情境，整合會員、商品、供應商與訂單等資訊，提供一個簡單但完整的資料管理系統示例。它不僅適合展示資料庫設計，也能作為後端開發與網頁互動的實作練習。
